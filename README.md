# Tracer

> Executive Material 3 Android Application & Autonomous Deep Work Flight System

Tracer is an executive goal navigation and cognitive pacing mobile system built as a first-class Android application backed by Capacitor Android, React 19, Vite, and Tailwind CSS.

## Architecture & Features

- **Executive Material 3 Ergonomics**: Edge-to-edge transparent system bars, 48dp minimum touch targets, native hardware/predictive back button interception, and tactile haptic feedback (`Capacitor Haptics`).
- **Deep Work Focus HUD**: Globally hoisted, multi-screen persistent focus session controller with radial countdown ring and ambient sound generation.
- **Flight Telemetry & Critical Path Method (CPM)**: Real-time velocity tracking, buffer float computation, and critical slip detection.
- **Contextual Biometric Security**: AES-GCM encrypted notes and private reflection vaults with biometric/PIN authentication.
- **Autonomous Multi-Agent Swarm**: Peer-to-peer agent collaboration architecture with continuous closed-loop product perfection.

## Development

```bash
# Install dependencies
npm install

# Run web dev server
npm run dev

# Run test suite
npm test

# Build and sync to Android
npm run android:sync

# Open in Android Studio
npm run android:open
```
